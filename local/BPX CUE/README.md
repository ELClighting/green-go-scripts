# (W)BPX CUE

* 20/05/26 Chad.P (W)BPX(SP) 5.2.2



Adds a toggleable function that enables cues to be sent from a belt pack



2ch 

\- toggled on/off by a simultaneous press of channel talk 1 \& 2 

\- retains talk function and allows cues to be sent using the call buttons 3 \& 4 for the respective channels 1 \& 2



3ch

\- toggled on/off by a simultaneous press of channel talk 1 \& 2 \& 3, this can also be cancelled/reverted by use of ether encoder

\- overwrites talk function and allows individual cues via the respective talk button and or "all" cues from button 4



4ch

\- toggled on/off by a simultaneous press of channel talk 1 \& 2 \& 3 \& 4, this can also be cancelled/reverted by use of ether encoder 

\- overwrites talk function and allows individual cues via the respective talk button
